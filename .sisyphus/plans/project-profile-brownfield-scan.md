## Architecture

- **Pattern**: Monorepo with full-stack separation + internal packages
- **Frontend**: apps/web/ — React SPA with Vite, ~1,116 shared components, 37 UI modules
- **Backend**: backend/ — Express REST API, 37 domain modules, CQRS event bus
- **Agent Service**: agent-service/ — FastAPI microservice for LLM agents
- **Shared Types**: shared-types/ — cross-stack TypeScript types
- **Core UI**: categories/@orthoplus/core/packages/ui/ — 50+ design system components
- **Database**: PostgreSQL 16 multi-schema (18 schemas, 180 models in Prisma)

### Frontend Architecture (DDD-lite / Clean Architecture parcial)
```
modules/<domain>/
  ├── domain/          # Entities, repositories (interfaces)
  ├── application/     # Use-cases
  ├── infrastructure/  # Repos concretos, adapters, API clients
  ├── ui/              # Pages, components, tabs
  └── hooks/           # Domain-specific hooks
```

### Backend Architecture (Modular monolith)
```
src/modules/<domain>/
  ├── api/             # Controllers, routes
  ├── application/     # Services, use-cases
  ├── domain/          # Entities, value objects
  ├── infrastructure/  # Repositories, external integrations
  └── __tests__/       # Unit tests
```

## Conventions

- **File naming**:
  - Frontend: PascalCase for components (StatsCard.tsx), camelCase for hooks/utils (usePatients.ts)
  - Backend: PascalCase for classes (AgendaService.ts), camelCase for files
  - Shared: kebab-case for configs (vite.config.ts)
- **Branch pattern**: main (production), develop (integration), feat/*, fix/*, omk/*
- **Commit style**: Conventional Commits (feat(ui):, refactor(backend):, docs:, fix(deploy):)
- **Test location**:
  - Backend: backend/tests/unit/*.test.ts (Jest)
  - Frontend: apps/web/src/**/*.test.{ts,tsx} (Vitest)
  - E2E: tests/e2e/*.spec.ts (Playwright)
- **Documentation**: AGENTS.md (agent-focused), README.md (human-focused), docs/ARCHITECTURE.md, docs/CATEGORIES.md

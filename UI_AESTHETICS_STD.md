# OrthoPlus SaaS Premium UI Standard v1.0

This standard defines the "High-Fidelity" visual language for the OrthoPlus Enterprise platform.

## 1. Glassmorphism Scale
- **.glass**: Default border (border-white/10), backdrop-blur-md, soft shadow.
- **.glass-deep**: Intensified border (border-primary/20), backdrop-blur-xl, deep shadow-neon-cyan/10. Use for main page containers.

## 2. Typography & Colors
- **Main Titles**: \`gradient-text\` (Neon Cyan to Sky Blue), font-extrabold.
- **Primary Brand**: \`hsl(186, 100%, 42%)\` (Neon Cyan).
- **Secondary Brand**: \`hsl(173, 58%, 39%)\` (Sage Clinic).

## 3. Interaction Patterns
- **Hover Scale**: All interactive cards must support \`hover:scale-[1.02]\` with a 300ms duration.
- **Glow states**: Active elements should emit a subtle \`shadow-neon-cyan/20\`.

## 👤 Cadastro de Pacientes Aprimorado

### Novo Campo: Status do Paciente

Agora você pode classificar pacientes em **14 status diferentes**:

- **Prospect** 🆕 - Novo lead (padrão)
- **Tratamento** 🦷 - Em tratamento ativo
- **Concluído** ✅ - Tratamento finalizado
- **Contenção** 🔒 - Fase de contenção
- **Abandono** ⚠️ - Abandonou o tratamento
- **Afastamento Temporário** ⏸️ - Pausa no tratamento
- **Inativo** 💤 - Paciente inativo
- E mais 7 status especializados...

**Como usar:**
1. No formulário de cadastro, selecione o status apropriado
2. O sistema rastreia automaticamente mudanças de status
3. Visualize o histórico completo na Timeline

### Nova Aba: Dados de Marketing

Rastreie a origem dos seus pacientes:

- **Campanha** - Ex: "Campanha Verão 2024"
- **Origem** - Ex: "Google Ads", "Facebook"
- **Evento** - Ex: "Feira de Saúde"
- **Promotor** - Nome do promotor
- **Telemarketing** - Agente de telemarketing
- **Indicação** - Nome de quem indicou

**Benefício:** Calcule o ROI de cada campanha e otimize investimentos em marketing.

## 🗂️ Ficha Unificada do Paciente

### Uma Única Tela, Todas as Informações

Agora, ao clicar em um paciente, você acessa **7 abas em uma única tela**:

1. **📋 Dados Cadastrais**
   - Informações pessoais
   - Contato
   - Dados de marketing

2. **🩺 Prontuário**
   - Histórico clínico
   - Anamnese
   - Alergias e doenças

3. **🦷 Odontograma**
   - Mapa dentário visual
   - Status de cada dente

4. **📷 Imagens/Radiografias**
   - Visualizador de imagens
   - Análise por IA
   - Zoom e anotações

5. **📝 Plano de Tratamento**
   - Procedimentos planejados
   - Procedimentos realizados
   - Valores

6. **💰 Financeiro**
   - Orçamentos
   - Contas a receber
   - Histórico de pagamentos

7. **📅 Timeline**
   - Histórico completo
   - Consultas
   - Mudanças de status
   - Orçamentos

**Como navegar:**
- Clique nas abas no topo para alternar
- Todas as informações são carregadas rapidamente
- Não é mais necessário alternar entre páginas diferentes

## 🔍 Busca Global (Cmd+K)

### Encontre Qualquer Coisa Instantaneamente

**Como ativar:**
- **Mac:** `Cmd + K`
- **Windows:** `Ctrl + K`
- **Ou clique no ícone de busca** 🔍 no header

**O que você pode buscar:**
- Pacientes (por nome, CPF, telefone)
- Orçamentos (por número ou paciente)
- Agendamentos (por data ou paciente)

**Como usar:**
1. Pressione `Cmd+K` / `Ctrl+K`
2. Digite o termo de busca
3. Veja resultados categorizados
4. Clique para navegar diretamente

**Dica:** Use para acesso super rápido a qualquer paciente!

## 📊 Dashboard de ROI de Marketing

### Nova Página: Análise Comercial

**Localização:** Menu CRESCIMENTO → Dashboard Comercial

**Métricas Disponíveis:**

1. **CAC (Custo de Aquisição)**
   - Quanto você gasta para adquirir cada paciente

2. **ROI Geral**
   - Retorno sobre investimento em marketing

3. **Taxa de Conversão**
   - % de leads que viraram pacientes

4. **ROI por Campanha**
   - Qual campanha traz melhor retorno

5. **Performance por Origem**
   - Qual canal (Google, Facebook, etc) performa melhor

**Como usar:**
1. Preencha dados de marketing nos cadastros de pacientes
2. O dashboard calcula automaticamente
3. Use para decidir onde investir em marketing

## ❓ Perguntas Frequentes

### P: Onde está o menu PEP?
**R:** O PEP agora está integrado à ficha do paciente. Clique em um paciente e acesse a aba "Prontuário".

### P: Como altero o status de um paciente?
**R:** 
1. Clique no paciente
2. Vá para a aba "Dados Cadastrais"
3. Selecione o novo status no campo "Status do Paciente"
4. Clique em "Salvar"

### P: Como vejo o histórico de mudanças de status?
**R:** Na ficha do paciente, vá para a aba "Timeline". Todas as mudanças de status ficam registradas lá.

### P: Onde cadastro dados de marketing?
**R:** No formulário de cadastro de paciente, vá para a aba "Marketing" (7ª aba).

### P: Como uso a busca global?
**R:** Pressione `Cmd+K` (Mac) ou `Ctrl+K` (Windows) e comece a digitar.

### P: Onde vejo o ROI das minhas campanhas?
**R:** Menu CRESCIMENTO → Dashboard Comercial

### P: Como ativo uma funcionalidade que está desabilitada?
**R:** Usuários ADMIN podem ir em CONFIGURAÇÕES → Gestão de Módulos e ativar/desativar módulos.

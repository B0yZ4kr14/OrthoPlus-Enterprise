# Visao — OrthoPlus Enterprise

## Proposito

Sistema completo de gestao clinica, financeira e comercial para clinicas odontologicas.
Multi-clinica, multi-tenant, seguro.

## Escopo

### Modulos Clinicos
- Pacientes, Agenda, PEP, Dentistas, Procedimentos

### Modulos Financeiros
- Financeiro, Orcamentos, Faturamento, PDV, Inadimplencia, Split Pagamento

### Modulos Administrativos
- Auth, Configuracoes, Funcionarios, Inventario, LGPD

### Modulos Avancados
- TISS, CRM, Marketing, Teleodontologia, IA Radiografia, Fidelidade, BI, NFE, Crypto

### Infraestrutura
- Memory Hub, Agent Service, Analytics, Notifications

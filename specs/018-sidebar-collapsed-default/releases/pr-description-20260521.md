## Summary

Implementa **Sidebar com Categorias Recolhidas por Padrao** para o OrthoPlus Enterprise. Todas as categorias de modulos na sidebar iniciam recolhidas, com controle de expansao individual por categoria, persistencia de estado no localStorage por usuario/clinica, e animacoes premium com Framer Motion.

## Specification

- **Feature Spec**: [spec.md](../spec.md)
- **Short Name**: `sidebar-collapsed-default`
- **Priority**: P2 — UX Enhancement

### Key Requirements

- **FR-001**: Estado de colapso/expansao independente por categoria (MenuGroup)
- **FR-002**: Toggle de categoria via click/teclado (Enter/Space) com cursor pointer
- **FR-003**: Animacoes de transicao (300ms, stagger 40ms, easing `[0, 0, 0.2, 1]`)
- **FR-004**: Persistencia localStorage com chave scoped por `userId:clinicId`
- **FR-005**: Auto-expand da categoria ativa baseada na rota atual

## Implementation

### Architecture Decisions

- **Estado**: Migracao de React Context -> Zustand store + persist middleware (alinhado com Constitution FE-4)
- **Persistencia**: Chave `orthoplus:sidebar:groups:{userId}:{clinicId}` para isolamento multi-tenant
- **Animacoes**: Variantes customizadas em `lib/animations.ts` (chevronRotate, categoryContent, categoryItem)
- **Acessibilidade**: ARIA attributes (`aria-expanded`, `aria-controls`), keyboard navigation, focus visible

### Files Changed

- `apps/web/src/stores/sidebarStore.ts` — Zustand store com persistencia scoped
- `apps/web/src/core/layout/Sidebar/SidebarGroup.tsx` — Toggle + animacoes + ARIA
- `apps/web/src/core/layout/Sidebar/SidebarGroup.test.tsx` — 9 testes (expandido de 2)
- `apps/web/src/contexts/AuthContext.tsx` — Logout cleanup de localStorage

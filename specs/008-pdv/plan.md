## Summary

This plan implements **Ponto de Venda (PDV)** for OrthoPlus Enterprise, a brownfield feature targeting existing module `point_of_sale` (backend) and `pointofsale` (frontend). The approach is incremental: enhance existing Prisma models, extend Express controllers, and build/adapt React UI components with Clean Architecture where applicable.

**Primary requirement**: Registro completo de transações de venda.
**Technical approach**: Prisma migration → Backend API extension → Frontend module enhancement → Integration tests

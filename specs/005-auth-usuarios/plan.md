## Summary

This plan implements **Autenticação e Controle de Acesso** for OrthoPlus Enterprise, a brownfield feature targeting existing module `auth` (backend) and `auth` (frontend). The approach is incremental: enhance existing Prisma models, extend Express controllers, and build/adapt React UI components with Clean Architecture where applicable.

**Primary requirement**: Sistema de login baseado em tokens JWT.
**Technical approach**: Prisma migration → Backend API extension → Frontend module enhancement → Integration tests

## Notes

- **Brownfield**: Module `auth` already exists — extend, don't rebuild
- **CA modules**: If `auth` uses Clean Architecture, follow existing patterns (domain → application → infrastructure)
- **Non-CA modules**: Use hooks + apiClient directly (existing pattern)
- **Autogenerated**: Never edit `apps/web/src/types/database.ts`
- **Date utils**: Use `lib/utils/date.utils.ts` (not date-fns directly)
- **Auth**: Use `useAuth()` from `contexts/AuthContext.tsx`

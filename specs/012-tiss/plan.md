## Summary

This plan implements **Integração TISS e Convênios** for OrthoPlus Enterprise, a brownfield feature targeting existing module `tiss_integration` (backend) and `tissintegration` (frontend). The approach is incremental: enhance existing Prisma models, extend Express controllers, and build/adapt React UI components with Clean Architecture where applicable.

**Primary requirement**: Gestão de operadoras de saúde.
**Technical approach**: Prisma migration → Backend API extension → Frontend module enhancement → Integration tests

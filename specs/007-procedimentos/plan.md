## Summary

This plan implements **Catálogo de Procedimentos** for OrthoPlus Enterprise, a brownfield feature targeting existing module `procedure_catalog` (backend) and `procedurecatalog` (frontend). The approach is incremental: enhance existing Prisma models, extend Express controllers, and build/adapt React UI components with Clean Architecture where applicable.

**Primary requirement**: Gestão completa do catálogo de procedimentos odontológicos.
**Technical approach**: Prisma migration → Backend API extension → Frontend module enhancement → Integration tests

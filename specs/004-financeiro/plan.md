## Summary

This plan implements **Gestão Financeira** for OrthoPlus Enterprise, a brownfield feature targeting existing module `financeiro` (backend) and `financeiro` (frontend). The approach is incremental: enhance existing Prisma models, extend Express controllers, and build/adapt React UI components with Clean Architecture where applicable.

**Primary requirement**: CRUD de receitas e despesas com categorização.
**Technical approach**: Prisma migration → Backend API extension → Frontend module enhancement → Integration tests

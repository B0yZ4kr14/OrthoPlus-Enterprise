## Summary

This plan implements **Gestão de Pacientes** for OrthoPlus Enterprise, a brownfield feature targeting existing module `pacientes` (backend) and `pacientes` (frontend). The approach is incremental: enhance existing Prisma models, extend Express controllers, and build/adapt React UI components with Clean Architecture where applicable.

**Primary requirement**: Sistema deve permitir criar, ler, atualizar e excluir registros de pacientes com validações de dados brasileiros.
**Technical approach**: Prisma migration → Backend API extension → Frontend module enhancement → Integration tests

## Summary

This plan implements **Gestão de Orçamentos** for OrthoPlus Enterprise, a brownfield feature targeting existing module `budget_management` (backend) and `budgetmanagement` (frontend). The approach is incremental: enhance existing Prisma models, extend Express controllers, and build/adapt React UI components with Clean Architecture where applicable.

**Primary requirement**: Sistema deve permitir criar, ler, atualizar e excluir orçamentos de tratamento.
**Technical approach**: Prisma migration → Backend API extension → Frontend module enhancement → Integration tests

## Summary

IA Radiografia module provides AI-powered automated analysis of dental radiographs with LGPD compliance, audit trails, and dentist review workflow. This PR delivers the MVP covering upload + AI analysis (US1), dentist review (US2), and consent management (US3), plus insights dashboard and comparison tools (US4 partial).

## What Could Improve (Start/Stop Doing)

1. **Spec gap: storage backend**: The spec did not explicitly state that local filesystem storage is acceptable for MVP. This caused confusion about whether T017 (real upload) was "complete" or "placeholder."

2. **Frontend endpoint drift**: `PatientRadiographyTimeline.tsx` had a wrong endpoint path (`/ia/analises-radiograficas` instead of `/ia-radiografia/analises`). This slipped through because there was no integration test validating the full frontend→backend contract.

3. **Deferred task tracking**: T007 was marked "deferred" in tasks.md but was actually implemented. The task tracker became slightly inconsistent with reality.

4. **E2E test absence**: T016 (E2E upload flow) was recognized as important but never prioritized. A single E2E test would have caught the endpoint drift and CORS issues.

5. **Review timing**: The staff review was run after most implementation was done. Running it earlier (e.g., after Phase 3 — US1 complete) could have caught the `as any` and endpoint issues sooner.

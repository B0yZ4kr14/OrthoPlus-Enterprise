# Antigravity Context - OrthoPlus Enterprise

> Contexto rápido para o Antigravity continuar o trabalho

---

## 🎯 Resumo do Projeto

**OrthoPlus Enterprise** é um SaaS odontológico com:
- **Backend:** Node.js 20 + Express + TypeScript + PostgreSQL
- **Frontend:** React 19 + Vite + TypeScript + Tailwind
- **AI Service:** Python 3.14 + FastAPI + Agno (LLM agents)

---

## 📂 Estrutura Principal

```
OrthoPlus-Enterprise/
├── backend/              # Node.js API (porta 3005)
│   ├── src/modules/      # Módulos do sistema
│   │   └── agents/       # NOVO: Integração com Agent Service
│   └── package.json
├── apps/web/             # Frontend React (porta 5173)
├── agent-service/        # Python AI Service (porta 8000)
│   ├── src/
│   │   ├── agents/       # Agents especializados
│   │   ├── models/       # Model Router (fallback)
│   │   └── workflows/    # Orquestração
│   └── requirements.txt
└── .antigravity-context.md  # Este arquivo
```

---

## 🚀 Serviços para Iniciar

```bash
# 1. Agent Service (Python)
cd agent-service
source venv/bin/activate
python src/main.py

# 2. Backend (Node.js)
cd backend
npm run dev

# 3. Frontend (React)
cd apps/web
npm run dev
```

## ⚡ Feature Principal: Model Routing

O **Agent Service** tem **roteamento automático** entre providers:

```
Gemini (Primary) ──quota exceeded──► OpenRouter (Fallback)
       │                                    │
       └────── Circuit Breaker ─────────────┘
```

**Status:** ✅ Implementado e funcionando
**Limitação:** Ambos os providers gratuitos estão com quotas limitadas
